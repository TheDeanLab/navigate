***************
Code of Conduct
***************

Our community values respectful, constructive collaboration.

Expected Behavior
=================

- Be respectful.
- Provide actionable, constructive feedback.
- Keep communication focused on improving the software and documentation.

Unacceptable Behavior
=====================

- Harassment, discrimination, or personal attacks.
- Hostile or abusive language.
- Disruptive behavior in issues, pull requests, or discussions.

Reporting
=========

If you encounter behavior that violates this policy, open an issue on `GitHub Issues <https://github.com/TheDeanLab/navigate/issues>`_ and include relevant context.
